# 🎨 Визуальный редактор Workflow - Руководство

## ✨ Что нового

Теперь вам **не нужно писать SQL** для создания workflow! Полноценный визуальный редактор с drag-and-drop интерфейсом интегрирован в систему.

## 🚀 Быстрый старт

### 1. Откройте редактор

1. Запустите приложение: `http://localhost:3000`
2. Войдите в систему
3. В левом меню нажмите **🎨 Редактор шаблонов**

### 2. Создайте первый workflow

**Шаг 1: Добавьте функции**
- Слева панель с 8 доступными функциями
- Перетащите функцию на холст (drag & drop)
- Каждая функция показывает:
  - Иконку
  - Название
  - Описание
  - Входные параметры
  - Выходные параметры

**Шаг 2: Соедините функции**
- Кликните на правый край узла
- Протяните линию к следующему узлу
- Стрелка покажет направление выполнения

**Шаг 3: Сохраните**
- Нажмите "💾 Сохранить"
- Введите название и описание
- Workflow сохранится в PostgreSQL

### 3. Управление шаблонами

**Загрузить существующий:**
- Нажмите "📂 Загрузить"
- Выберите шаблон из списка
- Редактируйте и сохраните изменения

**Удалить узел:**
- Кликните на узел (он выделится)
- Нажмите "🗑️ Удалить узел"

**Создать новый:**
- Нажмите "➕ Новый"
- Холст очистится

**Удалить шаблон:**
- Откройте "📂 Загрузить"
- Нажмите "🗑️ Удалить" у нужного шаблона

## 📚 Доступные функции

### ➕ Add
- **Описание:** Складывает два числа
- **Вход:** a, b
- **Выход:** sum

### ✖️ Multiply
- **Описание:** Умножает два числа
- **Вход:** x, y
- **Выход:** product

### 👋 SayHello
- **Описание:** Приветствие
- **Вход:** name
- **Выход:** greeting

### 📝 LogMessage
- **Описание:** Логирование
- **Вход:** message
- **Выход:** timestamp

### 📦 CheckMaterial
- **Описание:** Проверка материала
- **Вход:** materialId
- **Выход:** available

### ⚙️ StartProcessing
- **Описание:** Начало обработки
- **Вход:** partName, machineId
- **Выход:** processId

### 📧 SendNotification
- **Описание:** Отправка уведомления
- **Вход:** recipient, message
- **Выход:** status

### ⏳ Wait
- **Описание:** Задержка
- **Вход:** seconds
- **Выход:** elapsed

## 🎯 Примеры workflow

### Пример 1: Калькулятор
```
Add (a=10, b=5) → Multiply (x=sum, y=3) → LogMessage (message=result)
Результат: (10 + 5) * 3 = 45
```

### Пример 2: Производственный процесс
```
CheckMaterial (materialId="MAT-001")
  → StartProcessing (partName="Деталь А", machineId="CNC-01")
  → SendNotification (recipient="operator@factory.com", message=processId)
```

### Пример 3: Приветствие с логом
```
SayHello (name="Иван") → LogMessage (message=greeting)
```

## 🔧 Технические детали

### Архитектура

**Frontend:**
- React Flow для визуализации
- Drag & Drop интерфейс
- Сохранение в формате nodes + edges

**Backend:**
- `WorkflowTemplatesController` - REST API
- `workflow_templates` таблица в PostgreSQL
- Поля: `nodes` (JSONB), `edges` (JSONB)

**API Endpoints:**
- `GET /api/workflow-templates` - список всех шаблонов
- `GET /api/workflow-templates/{id}` - получить шаблон
- `POST /api/workflow-templates` - создать шаблон
- `PUT /api/workflow-templates/{id}` - обновить шаблон
- `DELETE /api/workflow-templates/{id}` - удалить шаблон

### Формат данных

```json
{
  "name": "Тест калькулятор",
  "description": "Складывает и умножает числа",
  "nodes": [
    {
      "id": "node-1",
      "type": "default",
      "position": { "x": 100, "y": 100 },
      "data": {
        "functionClass": "Backend.Services.WorkflowFunctions.ExampleWorkflowFunctions",
        "functionName": "Add",
        "needParam": ["a", "b"],
        "paramReturn": "sum"
      }
    }
  ],
  "edges": [
    {
      "id": "edge-1",
      "source": "node-1",
      "target": "node-2"
    }
  ]
}
```

## 🔮 Следующие шаги

1. **Добавьте свои функции:**
   - Создайте класс в `Backend/Services/WorkflowFunctions/`
   - Зарегистрируйте в `Program.cs`
   - Добавьте в `availableFunctions` в `WorkflowTemplateEditor.jsx`

2. **Интеграция с выполнением:**
   - Шаблоны из редактора автоматически доступны для запуска
   - Используйте `POST /api/workflow/start` с `wf_type` = название шаблона

3. **Расширенные возможности:**
   - Условные переходы (if/else)
   - Циклы (for/while)
   - Параллельное выполнение
   - Обработка ошибок

## 🐛 Troubleshooting

**Функции не перетаскиваются:**
- Проверьте, что браузер поддерживает Drag & Drop
- Попробуйте обновить страницу

**Не сохраняется в БД:**
- Проверьте консоль браузера (F12)
- Убедитесь, что Backend запущен
- Проверьте подключение к PostgreSQL

**Шаблон не загружается:**
- Проверьте формат данных в БД
- Убедитесь, что `nodes` и `edges` - валидный JSON

**Workflow не выполняется:**
- Проверьте, что все функции зарегистрированы в `Program.cs`
- Убедитесь, что параметры передаются корректно
- Проверьте логи Backend
