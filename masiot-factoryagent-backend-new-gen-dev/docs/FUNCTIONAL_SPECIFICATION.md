# Описание функциональных характеристик

## 1. Общие сведения

**MASIOT Factory Agent System** — комплексная информационная система управления производственными ресурсами на основе мультиагентной архитектуры. Система предназначена для моделирования технологических процессов, управления оборудованием, персоналом, инструментом и заготовками с привязкой к классификатору ОКПД-2.

### 1.1. Назначение системы

- Учёт и классификация производственных ресурсов (оборудование, персонал, инструмент, заготовки, техпроцессы).
- Визуальное конструирование и исполнение бизнес-процессов (workflow) через графический редактор.
- Автоматическое планирование операций с использованием агентного подхода и RabbitMQ.
- Интеграция с внешними системами через REST API и брокер сообщений.

### 1.2. Целевая аудитория

- Инженеры-технологи
- Операторы производства
- Системные администраторы
- Руководители производства

## 2. Функциональные требования

### 2.1. Управление деревом ресурсов

| ID | Функция | Описание |
|----|---------|----------|
| FR-01 | Иерархическое дерево | Просмотр и редактирование древовидной структуры производства (цехи, участки, агенты) |
| FR-02 | Drag-and-drop | Перемещение узлов и агентов между папками в режиме редактирования |
| FR-03 | Поиск | Быстрый поиск агентов по названию в боковой панели |
| FR-04 | Добавление веток | Создание новых папок (веток) в дереве |

### 2.2. Управление агентами

| ID | Функция | Описание |
|----|---------|----------|
| FR-05 | CRUD агентов | Создание, чтение, обновление, удаление агентов |
| FR-06 | Типы агентов | Поддержка типов: `tech_process`, `equipment`, `instrument`, `personnel`, `blank` |
| FR-07 | Параметры агентов | Добавление, редактирование и удаление параметров (имя, значение, единица измерения, описание) |
| FR-08 | Автосохранение в словарь | При сохранении параметров агента уникальные имена автоматически попадают в общий словарь параметров |
| FR-09 | ОКПД-2 | Автоматический поиск и присвоение кодов ОКПД-2 по названию заготовки |
| FR-10 | Импорт из Excel | Массовое создание агентов из `.xlsx` файлов (листы `equipment`, `instrument`, `personnel`, `blank`, `tech_process`) |

### 2.3. Словари и классификаторы

| ID | Функция | Описание |
|----|---------|----------|
| FR-11 | Словарь параметров | Центральный справочник возможных параметров с типами (`string`, `number`, `yes-no`) |
| FR-12 | Справочник ОКПД-2 | Полный иерархический классификатор ОКПД-2 |
| FR-13 | Маппинг заготовок | Сопоставление ключевых слов названий заготовок с кодами ОКПД-2 |

### 2.4. Workflow Engine

| ID | Функция | Описание |
|----|---------|----------|
| FR-14 | Визуальный редактор | Создание шаблонов workflow в графическом редакторе на базе React Flow |
| FR-15 | Реестр функций | Управление вызываемыми функциями (класс, метод, параметры, возвращаемое значение) |
| FR-16 | Запуск workflow | Исполнение шаблонов с отслеживанием шагов и статусов |
| FR-17 | Мониторинг | Просмотр активных и завершённых workflow, продолжение после ошибок |
| FR-18 | Планирование (WF1-WF5.2) | Автоматический цикл планирования: подготовка ТП → рассылка ресурсам → сбор ответов → СПР → расписание |

### 2.5. Интеграция и сообщения

| ID | Функция | Описание |
|----|---------|----------|
| FR-19 | RabbitMQ | Отправка и приём сообщений через брокер RabbitMQ (topic exchange `topic_logs`) |
| FR-20 | Маршрутизация | Отправка сообщений по `agent.{id}` и `okpd2.{code}` |
| FR-21 | Техпроцессы | Загрузка нормативных XLSX-файлов, парсинг операций, автоматическое создание агентов |

### 2.6. Безопасность и администрирование

| ID | Функция | Описание |
|----|---------|----------|
| FR-22 | Аутентификация | Двойная система: AES-256 для хранения паролей + BCrypt для проверки |
| FR-23 | Роли | `admin` и `user` — разграничение прав доступа |
| FR-24 | API-ключ мониторинга | Защищённые endpoint'ы статистики через `X-API-Key` |
| FR-25 | Журналирование | Структурированные логи через Serilog с ротацией по дням |

## 4. Роли и права доступа

### 4.1. Администратор (`admin`)
- Управление пользователями (CRUD)
- Управление словарём параметров
- Управление маппингом ОКПД-2 для заготовок
- Доступ к endpoint'ам мониторинга

### 4.2. Пользователь (`user`)
- Просмотр и редактирование дерева агентов
- Создание и запуск workflow
- Загрузка техпроцессов
- Работа с параметрами агентов

---

## 5. Ограничения и допущения

- Система рассчитана на работу в локальной сети предприятия (LAN).
- Все временные зоны на сервере и клиенте должны быть синхронизированы.
- Рекомендуется использование SSL/TLS при выносе API в публичную сеть.
- Максимальный размер загружаемого XLSX-файла: 10 МБ.
