# Release Notes

## Версия: 1.0.0 (Текущая)

**Дата сборки:** 2026-05-30

---

### Новые возможности

- **Агентная архитектура** — полноценная модель производственных ресурсов (оборудование, персонал, инструмент, заготовки, техпроцессы).
- **Иерархическое дерево** — drag-and-drop навигация, поиск, режим редактирования.
- **Workflow Engine** — визуальный редактор на React Flow, 55 встроенных функций, топологическая сортировка, исполнение через Reflection с DI.
- **Импорт Excel** — массовое создание агентов из `.xlsx` с автоматическим определением типа и подбором ОКПД-2.
- **Классификатор ОКПД-2** — полный справочник + автоматический маппинг заготовок.
- **Словарь параметров** — центральный реестр с типизацией (`string`, `number`, `yes-no`), авто-наполнение при сохранении агентов.
- **RabbitMQ-интеграция** — topic exchange, маршрутизация по `agent.{id}` и `okpd2.{code}`.
- **Мониторинг workflow** — автообновление, фильтры по статусам, продолжение после ошибок.
- **Планирование (WF1-WF5.2)** — автоматический цикл планирования операций с рассылкой ресурсам.
- **Двойная система безопасности паролей** — AES-256 (для просмотра админом) + BCrypt (для аутентификации).
- **API-ключ мониторинга** — защищённый доступ к статистике.
- **Docker-развёртывание** — `docker-compose.yml` с PostgreSQL, RabbitMQ, Backend, Frontend.
- **Swagger / OpenAPI** — полная документация API.

---

### Исправленные ошибки

- **Исправлено:** Ошибка подключения к PostgreSQL после восстановления бэкапа — пароль пользователя `postgres` теперь синхронизирован с `appsettings.json`.
- **Исправлено:** Словарь параметров (`parameter_dictionary`) не наполнялся при сохранении параметров агента — добавлена автоматическая синхронизация в `AgentsController`.
- **Исправлено:** Пустой массив параметров вызывал 500 ошибку при отсутствии таблицы `parameter_dictionary` в устаревших бэкапах — добавлена корректная обработка пустых результатов.

---

### Улучшения

- Улучшена обработка CORS для development-режима.
- Добавлены индексы на часто запрашиваемые поля (`agents.node_id`, `agents.okpd2_code`, `parameter_dictionary.name`).
- Оптимизирована загрузка дерева — агенты подгружаются параллельно через `Promise.all`.

---

### Архитектурные изменения

- Backend мигрирован с плоской структуры `WebApplication6` на многослойную архитектуру (`Controllers`, `Services`, `Repositories`, `DTOs`, `Middleware`).
- Добавлен `GlobalExceptionHandlerMiddleware` для единообразной обработки ошибок.
- Внедрён `WorkflowFunctionWhitelist` для предотвращения RCE при исполнении workflow.

### Известные проблемы

| ID | Проблема | Обходное решение | План исправления |
|----|----------|------------------|------------------|
| KN-01 | Два разных HTTP-клиента (`fetch` и `axios`) | Используйте `services/api.js` для всех запросов, кроме авторизации | v1.1.0 — унификация на `fetch` |
| KN-02 | Хардкод `localhost:3001` в `api.js` и `AgentPage.jsx` | Убедитесь, что backend запущен на этом порту | v1.1.0 — полная поддержка `.env` |
| KN-03 | `SubItemPage.jsx` и `SubSubItemPage.jsx` — мёртвый код | Не используйте эти страницы | v1.1.0 — удаление устаревших компонентов |
| KN-04 | RabbitMQ недоступен при старте backend — логи засоряются ошибками | Запустите RabbitMQ до backend | v1.1.0 — graceful degradation |
| KN-05 | Отсутствует JWT / OAuth — аутентификация через `localStorage` | Используйте HTTPS в production | v2.0.0 — внедрение JWT |

### Установка и обновление

См. `INSTALLATION_GUIDE.md`.

Для обновления с предыдущих версий:
1. Сделайте резервную копию БД.
2. Выполните `dotnet ef database update` в папке `Backend`.
3. Пересоберите frontend: `npm install && npm run build`.
4. Перезапустите службы.
