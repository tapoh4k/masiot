# 🔧 Работа БЕЗ внешнего API ОКП

## ✅ Хорошие новости!

Я добавил **fallback механизм**, который позволяет системе работать БЕЗ внешнего API классификатора!

## Как это работает

### 1. Приоритет поиска ОКП:

```
1. Локальный кэш (okp_cache) ← самый быстрый
   ↓ если не найдено
2. Старая таблица (okp_dictionary) ← fallback
   ↓ если не найдено
3. Внешний API ← если настроен
```

### 2. Что изменилось:

✅ **Добавлен fallback** на старую таблицу `okp_dictionary`
✅ **Пустой BaseUrl** в конфигурации - система будет использовать только локальные данные
✅ **Автоматическое кэширование** - данные из okp_dictionary копируются в okp_cache

## 📋 Что нужно сделать

### Шаг 1: Выполните миграцию БД
```bash
psql -U postgres -d agenti_db -f migrations/add_okp_cache_table.sql
```

### Шаг 2: Заполните тестовые данные ОКП (опционально)

Если у вас есть старые данные в `okp_dictionary`, они будут использоваться автоматически.

Если нет, добавьте несколько тестовых записей:

```sql
-- Подключитесь к БД
psql -U postgres -d agenti_db

-- Добавьте тестовые ОКП
INSERT INTO okp_dictionary (name, description) VALUES
('28.41.22.130', 'Станки токарные с ЧПУ'),
('28.41.23.110', 'Станки фрезерные с ЧПУ'),
('28.41.31.120', 'Станки сверлильные'),
('28.49.12.190', 'Центры обрабатывающие'),
('28.41.24.110', 'Станки шлифовальные')
ON CONFLICT (name) DO NOTHING;
```

### Шаг 3: Перезапустите Backend
```bash
cd Backend
dotnet run
```

### Шаг 4: Тестирование

1. Откройте http://localhost:5173
2. Войдите в систему
3. Перейдите в любую папку
4. Начните вводить: `Токарный станок`
5. **Результат:** Система найдёт ОКП из `okp_dictionary` и автоматически скопирует в кэш

## 🎯 Режимы работы

### Режим 1: БЕЗ API (текущий)
```json
"OkpApi": {
  "BaseUrl": "",  // ← пустой URL
  "TimeoutSeconds": 30
}
```
**Источники данных:** okp_cache → okp_dictionary

### Режим 2: С API (когда получите доступ)
```json
"OkpApi": {
  "BaseUrl": "https://api.okp.example.ru/v1",  // ← реальный URL
  "TimeoutSeconds": 30
}
```
**Источники данных:** okp_cache → okp_dictionary → внешний API

## ✅ Что будет работать БЕЗ API:

- ✅ Автопоиск ОКП (из okp_dictionary)
- ✅ Создание новых агентов
- ✅ Импорт XLSX
- ✅ Кэширование
- ✅ Все остальные функции

## ❌ Что НЕ будет работать БЕЗ API:

- ❌ Кнопка "Обновить кэш вручную" (но это не критично)
- ❌ Автоматическое обновление раз в 24 часа (но локальные данные останутся)

## 🔄 Переход на реальный API

Когда получите доступ к API классификатора:

1. Откройте `Backend/appsettings.json`
2. Замените пустой `BaseUrl` на реальный URL
3. Перезапустите Backend
4. Готово! Система начнёт использовать внешний API
