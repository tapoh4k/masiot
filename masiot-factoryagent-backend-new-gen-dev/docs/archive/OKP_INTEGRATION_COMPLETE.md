## Ключевые возможности

### Для пользователей:
1. **Автоматический поиск ОКП** - при вводе названия оборудования
2. **Умный выбор** - автоматический выбор если найден 1 результат
3. **Множественный выбор** - dropdown если найдено несколько вариантов
4. **Read-only поле** - ОКП нельзя изменить вручную
5. **Импорт XLSX** - автопоиск ОКП для агентов без кода

### Для администраторов:
1. **Статистика кэша** - количество записей, последнее обновление
2. **Ручное обновление** - кнопка принудительного обновления кэша
3. **Мониторинг** - просмотр состояния интеграции с API

### Автоматизация:
1. **Кэширование** - все запросы кэшируются в PostgreSQL
2. **Автообновление** - кэш обновляется раз в 24 часа
3. **Офлайн режим** - работа из кэша если API недоступен
4. **Автозапрос** - новые коды автоматически запрашиваются при обновлении

## Следующие шаги для запуска

### Шаг 1: Миграция БД
```bash
psql -U postgres -d agenti_db -f migrations/add_okp_cache_table.sql
```

### Шаг 2: Настройка Backend
Отредактируйте `Backend/appsettings.json`:
```json
{
  "OkpApi": {
    "BaseUrl": "https://api.okp.example.ru/v1",
    "TimeoutSeconds": 30
  }
}
```

**⚠️ ВАЖНО:** Замените URL на реальный адрес API классификатора ОКП!

### Шаг 3: Перезапуск
```bash
# Backend
cd Backend
dotnet restore
dotnet run

# Frontend (новый терминал)
npm install
npm run dev
```

### Шаг 4: Проверка
1. Откройте http://localhost:5173
2. Войдите как администратор (admin/admin)
3. Откройте Настройки → Кэш ОКП (Администратор)
4. Нажмите "Обновить кэш вручную" (первый раз)
5. Перейдите в любую папку
6. Начните вводить название оборудования
7. Проверьте автопоиск ОКП

## API Endpoints

### Доступные эндпоинты:
- `GET /api/okp/search?name={name}` - поиск по названию
- `GET /api/okp/code/{code}` - получение по коду
- `POST /api/okp/refresh-cache` - обновление кэша (админ)
- `GET /api/okp/cache-stats` - статистика

### Формат ответов API:
```json
// Поиск: GET /search?name=Токарный
[
  {
    "code": "28.41.22.130",
    "name": "Станки токарные с ЧПУ",
    "description": "Описание"
  }
]

// По коду: GET /code/28.41.22.130
{
  "code": "28.41.22.130",
  "name": "Станки токарные с ЧПУ",
  "description": "Описание"
}
```
