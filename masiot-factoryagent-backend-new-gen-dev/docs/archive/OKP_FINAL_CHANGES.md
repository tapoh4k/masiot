## 🎯 Как это работает

### Создание агента через форму (BranchPage):
1. Пользователь вводит название: "Токарный станок 16K20"
2. Система автоматически ищет ОКП через API (задержка 500мс)
3. ОКП автоматически выбирается
4. Пользователь выбирает параметры
5. Нажимает "Создать агента"
6. **ОКП автоматически добавляется как первый параметр**

### Создание агента через XLSX:
1. Пользователь загружает XLSX файл
2. Система парсит данные
3. Для каждого агента берёт ОКП из колонки
4. **ОКП автоматически добавляется как первый параметр**
5. Остальные параметры добавляются из других колонок

### Просмотр параметров агента:
1. Пользователь открывает агента
2. Видит таблицу параметров
3. **Параметр "Код ОКП" отображается первым**
4. **Поле read-only (серый фон)**
5. **Кнопка удаления отсутствует**
