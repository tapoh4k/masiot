# Руководство пользователя

## 1. Вход в систему

1. Откройте браузер и перейдите по адресу `http://localhost:5173`.
2. На странице входа введите логин и пароль.
3. По умолчанию создан пользователь:
   - **Логин:** `admin`
   - **Пароль:** `admin123`
4. Нажмите **Войти**.

---

## 2. Главная страница

После входа вы попадаете на главную страницу (`/`).

**Что здесь можно делать:**
- Загружать `.xlsx` файлы с техпроцессами (drag-and-drop или кнопка).
- Просматривать статистику по агентам (всего агентов, оборудование, персонал, инструмент, заготовки, техпроцессы).
- Видеть историю загрузок файлов.
- Переключиться в **режим редактирования дерева** (кнопка в интерфейсе).

---

## 3. Навигация по дереву (Sidebar)

Слева расположена панель дерева производственных ресурсов.

### 3.1. Структура дерева

- 🏠 **Главная** — переход на главную страницу.
- 📁 **Ветки** (цехи, участки, папки) — группировка агентов.
- 🔑 **Агенты** — конкретные ресурсы (станки, сотрудники, инструменты).

### 3.2. Поиск

Введите текст в поле «🔍 Поиск агентов...» — дерево отфильтруется в реальном времени.

### 3.3. Режим редактирования

1. Нажмите кнопку входа в режим редактирования.
2. Появится баннер «🔧 Режим редактирования».
3. **Добавление ветки:** введите имя в поле «Новый элемент…» и нажмите `+`.
4. **Перемещение:** захватите узел мышью (drag) и перетащите на целевую папку (drop).
5. **Перемещение на корневой уровень:** перетащите узел в зону «Переместить на первый уровень».
6. **Удаление:** нажмите `×` рядом с узлом (подтвердите в диалоге).
7. Нажмите **Выйти** для завершения редактирования.

---

## 4. Работа с веткой (BranchPage)

Кликните на папку (ветку) в дереве — откроется страница ветки.

### 4.1. Вкладка «Инфо»

Отображает статистику агентов внутри ветки (количество по типам).

### 4.2. Вкладка «Рабочий процесс»

Таблица со статусами workflow агентов этой ветки.

### 4.3. Вкладка «Параметры»

Форма создания нового агента:

1. **Имя агента** — введите название (например, «Токарный станок 16К20»).
2. **ОКПД-2** — при вводе имени длиннее 3 символов система автоматически предложит код ОКПД-2. Можно ввести код вручную (переключатель «Ввести вручную»).
3. **Количество** — количество единиц.
4. **Параметры** — нажмите «+ Добавить параметры», выберите из словаря или создайте новые.
5. Нажмите **Создать агента**.

---

## 5. Работа с агентом (AgentPage)

Кликните на агента в дереве — откроется карточка агента.

### 5.1. Вкладка «Информация об агенте»

**Параметры агента:**
- Таблица с текущими параметрами (имя, ед. изм., значение, описание).
- **Добавить параметры** — выбор из общего словаря.
- Измените значение в поле ввода.
- Нажмите **🗑️** для удаления параметра.
- Нажмите **Сохранить параметры** — изменения отправятся на сервер, а уникальные имена параметров автоматически попадут в общий словарь.

**Действия:**
- **Скачать архив** — выгрузка данных агента в JSON.
- **Удалить агента** — полное удаление.

### 5.2. Вкладка «Настройка Workflow»

1. Выберите шаблон workflow из списка.
2. Нажмите **Отправить в RabbitMQ** — подготовит и отправит сообщение.
3. Просмотр статуса готовности (`workflow_status`).

### 5.3. Вкладка «Создать агента»

Форма клонирования текущего агента с возможностью изменения параметров.

---

## 6. Редактор шаблонов workflow

Откройте через боковое меню «🎨 Редактор шаблонов».

### 6.1. Создание шаблона

1. В левой панели находится **палитра функций** (категории: RabbitMQ, AgentInfo, Planning и др.).
2. Перетащите функцию на холст — появится узел.
3. Соедините узлы рёбрами (от выхода одного к входу другого).
4. Двойной клик по узлу — просмотр информации о функции.
5. Введите **Название шаблона** вверху.
6. Нажмите **Сохранить** — шаблон сохранится в БД.

### 6.2. Типы узлов

| Узел | Цвет | Назначение |
|------|------|------------|
| ⚙️ Function | Зелёный | Одиночная исполняемая функция |
| 📦 WF | Оранжевый | Готовая цепочка функций |
| 🔗 SubWF | Фиолетовый | Подцепочка (вложенный шаблон) |

### 6.3. Управление функциями

Нажмите «+ Новая функция» — откроется форма:
- Название, описание
- Класс backend и имя метода
- Входные параметры (имя, тип, обязательность)
- Возвращаемое значение
- Иконка и тип узла

---

## 7. Мониторинг workflow

Страница «Мониторинг workflow» (доступна из редактора или по прямой ссылке).

- Автообновление каждые **3 секунды**.
- **Фильтры:** Все / Выполняются / Завершены / Ошибки.
- Карточка workflow показывает:
  - Текущий шаг
  - Длительность
  - Параметры
  - Список функций
- Кнопка **Продолжить** — запускает workflow с произвольного шага (при ошибке).

---

## 8. Импорт агентов из Excel

### 8.1. Подготовка файла

Создайте `.xlsx` с листами:
- `equipment` — оборудование
- `instrument` — инструмент
- `personnel` — персонал
- `blank` — заготовки
- `tech_process` — техпроцессы

Колонки (заголовки на русском):
- Название / Имя
- Описание
- Количество
- Профессия
- ОКПД-2 (опционально)
- Любые дополнительные колонки будут распознаны как параметры

### 8.2. Загрузка

1. Перетащите файл на главную страницу (зона drag-and-drop).
2. Или нажмите кнопку выбора файла.
3. Откроется модальное окно с предпросмотром.
4. Система автоматически:
   - Определит тип агента по имени листа
   - Подберёт ОКПД-2 по названию
   - Распределит параметры из колонок
5. Нажмите **Создать агентов**.

---

## 9. Настройки (⚙️)

Нажмите иконку шестерёнки в шапке.

### 9.1. Словарь параметров

- **Просмотр** всех параметров.
- **Добавление:** имя, описание, тип (`string` / `number` / `yes-no`), единица измерения.
- **Редактирование** и **удаление**.

### 9.2. Справочник ОКПД-2 (только admin)

- Управление маппингом «ключевое слово → код ОКПД-2».
- Массовая вставка через формат JSON/CSV.

---

## 10. Выход из системы

Нажмите иконку **Выход** (↩️) в правом верхнем углу.

---

## 11. Советы и подсказки

| Проблема | Решение |
|----------|---------|
| Дерево не загружается | Обновите страницу (F5), проверьте что backend запущен |
| Ошибка «Словарь параметров» | Проверьте подключение к БД, обновите страницу |
| Workflow завис на ошибке | Откройте Мониторинг → нажмите «Продолжить» и укажите шаг |
| Не сохраняются параметры | Убедитесь, что имя параметра не пустое |
| Нет ОКПД-2 в подсказке | Добавьте маппинг вручную через Настройки → Справочник ОКПД-2 |
