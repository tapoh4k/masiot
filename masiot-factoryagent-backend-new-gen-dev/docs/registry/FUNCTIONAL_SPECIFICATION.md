# Описание функциональных характеристик

**Продукт:** MAS-IOT  
**Версия:** 1.0.0

---

## 1. Управление иерархией агентов

- Создание, редактирование и удаление папок и агентов в древовидной структуре
- Поддержка неограниченной вложенности папок
- Перемещение агентов между папками
- Настройка иконок и позиций элементов

## 2. Управление агентами

- Создание агентов вручную и импорт из Excel (XLSX)
- Привязка агентов к узлам дерева
- Назначение типа: оборудование, персонал, заготовки, технологический процесс
- Указание профессии, количества, статуса
- Назначение кодов ОКПД-2

## 3. Параметры агентов

- Добавление произвольных параметров (имя, значение, единица измерения, описание)
- Автоматическая синхронизация параметров в общий словарь
- Массовое редактирование параметров

## 4. Workflow-движок

- Визуальный редактор workflow-шаблонов (React Flow)
- 55 встроенных функций: RabbitMQ, агенты, расписание, техпроцессы, планирование
- Запуск workflow на агентах
- Отслеживание шагов выполнения и статусов
- Возобновление workflow после ошибки

## 5. Обмен сообщениями (RabbitMQ)

- Отправка рабочих сообщений конкретному агенту
- Широковещательная рассылка по кодам ОКПД-2
- Отправка информации об агенте
- Определение новых workflow через сообщения
- **Сквозное шифрование сообщений (AES-256)**

## 6. Технологические процессы

- Импорт техпроцессов из Excel-файлов
- Хранение операций техпроцесса
- Привязка техпроцесса к агенту
- Автоматическое создание агентов из импортированных данных

## 7. Справочники

- Иерархический классификатор ОКПД-2
- Словарь параметров
- Маппинг заготовок на коды ОКПД-2

## 8. Расписание (TimeTable)

- Создание записей расписания по заказам
- Привязка к партнёрам и workflow
- Управление статусами записей

## 9. Безопасность

- Аутентификация пользователей
- Двухуровневая система паролей: BCrypt (хеш) + AES-256 (шифрование)
- Роли: admin, user, operator
- API-ключ для системного мониторинга

## 10. Мониторинг

- Статистика по агентам, пользователям, узлам дерева
- Логирование операций (Serilog)
- Health-check endpoint
