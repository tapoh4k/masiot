## Управление пользователями

### Создание пользователя

1. Войти под администратором
2. Перейти в раздел "Пользователи"
3. Нажать "Добавить пользователя"
4. Указать: логин (минимум 3 символа), пароль (минимум 6 символов), роль, ФИО
5. Пароль автоматически хешируется (BCrypt) и шифруется (AES-256)

### Роли

- **admin** — полный доступ, управление пользователями и справочниками
- **user** — работа с агентами, деревом, workflow
- **operator** — операционные задачи, запуск workflow

## Управление справочниками

### ОКПД-2

- Раздел "ОКПД-2" → создание/редактирование кодов
- Иерархия: раздел → группа → класс → подкласс → позиция
- Коды профессий: PROF.01 (Токарь), PROF.02 (Фрезеровщик) и т.д.

### Словарь параметров

- Автоматически пополняется при создании параметров агентов
- Ручное редактирование: имя, описание, тип, единица измерения

## Мониторинг системы

```bash
curl -H "X-API-Key: <ключ>" http://localhost:3001/api/monitoring/statistics
```

## Настройка шифрования RabbitMQ

В `appsettings.json`:
```json
{
  "RabbitMQ": {
    "EncryptMessages": true
  },
  "Encryption": {
    "Key": "32-байтный-ключ",
    "IV": "16-байтный-iv"
  }
}
```

Ключи должны быть одинаковыми на всех узлах, обменивающихся сообщениями через RabbitMQ.

## Backup и восстановление

```bash
# Backup
pg_dump -U postgres -d agenti_db > backup.sql

# Restore
psql -U postgres -c "DROP DATABASE agenti_db;"
psql -U postgres -c "CREATE DATABASE agenti_db;"
psql -U postgres -d agenti_db -f backup.sql
```
