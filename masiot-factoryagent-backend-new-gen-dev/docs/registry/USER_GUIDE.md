# Руководство пользователя

**Продукт:** MAS-IOT  
**Версия:** 1.0.0

---

## Вход в систему

1. Откройте браузер и перейдите по адресу `http://localhost:5173`
2. Введите логин и пароль
3. Стандартный администратор: `admin` / `admin123`

## Навигация

- **Левое меню** — иерархическое дерево папок и агентов
- **Верхняя панель** — кнопки создания, импорта, workflow
- **Центральная область** — рабочая зона выбранного элемента

## Работа с деревом

### Создание папки

1. Нажмите "Создать папку"
2. Введите название
3. Папка появится в дереве

### Создание агента

1. Выберите папку
2. Нажмите "Добавить агента"
3. Заполните: название, тип, профессия, количество
4. Сохраните

### Импорт из Excel

1. Нажмите "Создать агентов из XLSX"
2. Выберите файл Excel
3. Система автоматически создаст папки и агентов

## Workflow

### Создание шаблона

1. Откройте "Workflow Templates"
2. Нажмите "Создать новый"
3. Перетаскивайте функции из палитры
4. Соединяйте узлы стрелками
5. Сохраните шаблон

### Назначение workflow агенту

1. Откройте страницу агента
2. Перейдите на вкладку "Настройка Workflow"
3. Выберите нужные шаблоны
4. Нажмите "Отправить в RabbitMQ"

## ОКПД-2

- Каждому агенту можно назначить код ОКПД-2
- Используется для маршрутизации сообщений
- Заготовки автоматически маппятся на коды через справочник
